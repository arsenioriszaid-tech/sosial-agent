# Content Rules

Voice: builder / learner / operator.

Avoid generic AI hype, fake expertise, fake personal experience, unsupported claims, engagement bait, controversy bait, repetitive posts, excessive hashtags, and forced Exousia promotion.

Principles:
- Specific observation > generic opinion
- Concrete experience > recycled summary
- Useful insight > engagement bait
- Honest uncertainty > fake certainty

Every draft should contain a concrete observation, useful synthesis, or firsthand lesson. A question counts only when it is a substantive part of the analysis — never a mandatory hook. If there is no meaningful contribution, return SKIP.

## V0.1 canonical contract

Pipeline: research → verified facts → context → analysis → core observation → canonical draft → human review → platform adaptation.

- Canonical draft = complete thought (what happened + why relevant), 1–3 paragraphs, target 400–800 chars, no hard limit.
- Facts and interpretation must be labeled apart (Facts / Analysis / Take). Take is optional; absence of a take is fine.
- No mandatory hook, question, CTA, or engagement bait.
- SKIP when: headline repetition only; no meaningful observation; context too thin; main claim not trustworthy enough; or the draft is only interesting as controversy/engagement bait.
- Never invent user experience, opinions, or facts.
- Platform budgets (e.g. X 280 chars) constrain only the adaptation note, never the canonical draft. Never truncate mid-sentence; mark NEEDS_REVIEW when a human must adapt.
