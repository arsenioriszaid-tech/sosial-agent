# Sosial Agent

AI-assisted social media agent for research, content drafting, engagement analysis, and tester discovery.

## Purpose

Sosial Agent is a bounded internal tool for maintaining an active social presence while supporting targeted discovery of potential Exousia testers.

V0 is human-in-the-loop. It researches, analyzes, drafts, qualifies, and recommends. Public actions remain under human approval.

## Objectives

### A — Content Activation
Produce useful, specific content around AI, agentic AI, coding agents, developer tools, software building, and selected build-in-public work.

### B — Exousia Tester Discovery
Find and qualify developers with observable evidence of coding-agent use or relevant agentic-development work.

These objectives are deliberately separated. Exousia must not become a forced CTA in normal content.

## V0 Workflow

Research → Analyze → Draft/Qualify → Human Review → External Action

## V0 Prohibitions

No autonomous publishing, replies, likes, follows, DMs, deletion, profile changes, paid promotion, CAPTCHA/rate-limit bypass, mass engagement, credential storage, or deceptive identity.

## Evaluation

Run V0 as a 7-day experiment. Measure workload reduction, content quality, consistency, research relevance, qualified candidates, genuine conversations, and whether the user prefers the assisted workflow to doing it manually.

If evidence is weak, document the result and stop rather than automatically expanding scope.
